Horse Animation in Augmented Reality (AR) 

The Horse Animation in Augmented Reality (AR) project is a Unity-based application that demonstrates the integration of 3D models, animation, and AR technology. The project uses an Image Target to place a realistic 3D horse model into the real-world environment, allowing users to view and interact with the animated horse through a mobile device.

The horse model, imported from Sketchfab, includes separate Idle and Walk animation clips. These animations are managed using Unity's Animator Controller, enabling smooth transitions between different animation states. A stable environment and surrounding forest model are also included to create a more immersive and realistic scene.

The application is developed using Unity 6, where the AR Camera detects the image target and renders the virtual objects in real time. The project demonstrates key concepts such as importing 3D assets, applying textures and materials, configuring animation controllers, and creating an interactive AR experience.

# Features

* Realistic 3D horse model imported from Sketchfab.
* Separate Idle and Walk animations.
* Animation controlled using Unity's Animator Controller.
* AR visualization using an Image Target.
* Stable and forest environment for enhanced realism.
* Interactive and immersive 3D experience.

# Technologies Used

* Unity 6
* C#
* Augmented Reality (AR)
* Image Target Tracking
* Animator Controller
* Sketchfab 3D Assets

The project successfully displays an animated horse in an augmented reality environment. When the image target is detected, the horse and its surroundings are rendered in the real world, showcasing the effective use of Unity's animation system and AR capabilities. This project provides practical experience in 3D modeling, animation integration, and augmented reality application development.
